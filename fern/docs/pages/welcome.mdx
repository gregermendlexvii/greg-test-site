## Get started

<Steps>
<Step title="Note the base URL">

All REST endpoints are served from:

```
https://api.plantstore.dev/v3
```

</Step>
<Step title="Log in">

Exchange a username and password for a session token. See [Authentication](/authentication) for details.

```bash
curl "https://api.plantstore.dev/v3/user/auth/login?username=john_doe&password=$PLANTSTORE_PASSWORD"
```

```json
{ "token": "abc123token", "expiresIn": 3600 }
```

</Step>
<Step title="Make your first request">

Search the catalog for plants that are available to order:

```bash
curl "https://api.plantstore.dev/v3/plant/search/status?status=available&limit=20"
```

```json
{
  "data": [
    { "id": 101, "name": "Fern", "status": "available", "tags": ["green", "leafy"] },
    { "id": 102, "name": "Palm", "status": "available", "tags": ["tropical"] }
  ],
  "nextCursor": "eyJpZCI6MTAzfQ"
}
```

</Step>
<Step title="Go further">

- [Pagination](/pagination): page through search results
- [API reference](/docs/api-reference/plant/add-plant): every endpoint, with an interactive explorer

</Step>
</Steps>
